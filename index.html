ABOUT THE PROJECT

Technology with Purpose

A single-file educational prototype combining camera hand tracking, a learning interface and CSS 3D effects.

⚙️ Technology stack

HTML — page structure and navigation.

CSS — responsive layout, neon styling and 3D-style animations.

JavaScript — navigation, letter explorer, camera controls and interactions.

MediaPipe Hands — hand landmark estimation in the browser.

🪄 Interactive 3D animation

Move your pointer over the visual to change its perspective, or toggle its animation.

Important limitations

This project is an educational prototype. Landmark detection does not automatically mean accurate sign-language recognition. The simple classifier supports only a small number of approximate static shapes. The text-to-hand feature is a character explorer, not a full translation system. The 3D animation is a visual effect and is not a tracked 3D hand model.

Sign languages differ by region and have their own grammar. For real communication, use verified learning materials and involve Deaf sign-language users and qualified instructors.
