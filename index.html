OUR MISSION

About संकेतवाणी

हाथों की भाषा को सीखने के लिए एक सरल डिजिटल शुरुआत।

हाथों की भाषा, अब हर किसी के लिए

संकेतवाणी एक educational project है जो computer vision और sign-language learning को एक सरल browser experience में जोड़ता है। विद्यार्थी हाथ के landmarks, finger positions और gesture classification की मूल अवधारणाएँ सीख सकते हैं।

यह प्रोजेक्ट सांकेतिक भाषा के प्रति जागरूकता और accessible technology में रुचि बढ़ाने के लिए बनाया गया है। यह पूर्ण sign-language translator या प्रमाणित शिक्षण सामग्री का विकल्प नहीं है।

Project Features

एक फाइल में, बिना build process के।

📷 Hand → Text

Browser camera, real-time landmarks, conservative static gesture rules और practice text.

🔤 Text → Hand

Alphabet selection और schematic SVG learning references.

📱 Responsive

मोबाइल और लैपटॉप के लिए responsive interface.

🔒 Camera Control

कैमरा केवल user action के बाद शुरू होता है और Stop पर tracks बंद होते हैं।
